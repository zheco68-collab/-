# 小红书评论数据采集脚本说明文档

本文档介绍了基于 DrissionPage 开发的小红书笔记评论抓取脚本。该脚本通过监听浏览器底层网络数据包的方式，自动拦截并解析小红书后端的 JSON 数据，从而实现高效、稳定的评论采集，并将结果导出为 CSV 文件。


## 核心特性

底层抓包解析：不依赖易变的网页前端 HTML DOM 结构，直接监听 /api/sns/web/v2/comment/page 数据接口，获取最原始、最完整的 JSON 数据。

全自动翻页：内置基于 cursor 的游标追踪与页面滚动（Scroll）逻辑，自动模拟真人向下滑动，触发下一页评论的加载。

多维度数据提取：精准提取并格式化每一条评论的核心价值数据。

稳定与容错：包含完备的异常捕获（如：节点找不到时采用通用向下滚动）和频率控制（防封号/风控阻断）。

## 环境依赖与安装

在运行此脚本之前，请确保您的计算机上已安装 Python 3.6+，并安装了核心自动化库 DrissionPage。

# 安装 DrissionPage 库
pip install DrissionPage


提示：DrissionPage 是一个集成了控制浏览器和收发请求的自动化工具。首次运行时，它会自动接管或启动您的 Chromium 内核浏览器（如 Chrome 或 Edge）。

## 使用指南

1. 修改目标笔记 URL

使用文本编辑器打开 Python 脚本，找到代码中的 dp.get(...) 这一行。将括号内的 URL 替换为您想要爬取的小红书笔记链接。

# 替换为你需要抓取的笔记链接
dp.get('[https://www.xiaohongshu.com/explore/您的笔记ID](https://www.xiaohongshu.com/explore/你的笔记ID)')


2. 运行脚本

在终端或命令行中执行该 Python 脚本：

python your_script_name.py


3. 查看运行状态与结果

脚本启动后会弹出一个浏览器窗口并自动打开目标页面。

控制台会实时打印当前的爬取进度（如：“正在爬取第 1 页数据”）以及每条抓取到的评论字典。

当控制台提示 “数据爬取完成并已保存！” 或 “找不到下一页的 cursor，爬取结束。” 时，表示抓取完毕。

在脚本同级目录下，找到 小红书评论.csv 文件，使用 Excel 或 WPS 打开即可进行数据分析。

## 代码工作流原理解析

环境初始化：创建 ChromiumPage 对象，接管浏览器。创建并写入 CSV 的表头。

开启网络监听：通过 dp.listen.start('comment/page') 设定规则，告诉浏览器拦截所有包含该关键词的异步数据包。

循环捕获与解析：

脚本进入 while True 循环，挂起并等待 dp.listen.wait() 捕获到目标数据包。

数据包到达后，提取 response.body 中的 JSON 数据，遍历 comments 列表。

进行时间戳转换和缺省值处理（.get() 方法防止报错），将数据写入 CSV。

模拟滚动触发加载：提取 JSON 中的 cursor（下一页游标），并在页面上寻找对应的特定前端元素 ID 进行滚动定位，以此欺骗小红书的前端执行下一页加载请求。

休眠保护：使用 time.sleep(1.5) 进行节流，模拟人类阅读速度，防止被服务端安全策略拦截。
